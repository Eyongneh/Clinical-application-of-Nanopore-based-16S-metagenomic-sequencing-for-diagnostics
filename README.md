# Clinical Application of Nanopore-Based 16S Metagenomic Sequencing for Diagnostics

## Project Overview

This repository documents my hands-on exploration of Oxford Nanopore 16S rDNA sequencing for bacterial identification and diagnostic microbiology applications. 
The project covers taxonomic classification, validation using BLAST, targeted read extraction, and workflow execution using Emu and Trana.

### Skills Demonstrated

- Oxford Nanopore Technologies (ONT)
- 16S rDNA sequencing analysis
- Taxonomic classification with Emu
- Sequence validation using BLAST
- Linux and WSL
- Nextflow workflows
- Pixi package management
- Bioinformatics troubleshooting
- GitHub Codespaces
