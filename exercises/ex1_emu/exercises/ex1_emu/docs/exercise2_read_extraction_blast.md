# Exercise 2: Read Extraction and BLAST Validation of Salmonella enterica

## Objective

The objective of this exercise was to investigate taxonomic classifications generated by Emu at the read level and independently validate the identification of a selected organism using NCBI BLAST.

Following the taxonomic profiling performed in Exercise 1, reads assigned to *Salmonella enterica* were extracted from the Emu alignment output and compared against the NCBI nucleotide database to assess the accuracy of the classification.

---

## Background

Taxonomic classification tools such as Emu estimate the relative abundance of organisms present in a sequencing dataset. Although these tools provide highly useful classifications, it is often necessary to verify important findings by examining the underlying sequencing reads.

By extracting reads assigned to a specific organism and comparing them against a large public sequence database, we can determine whether the classification is biologically plausible and supported by sequence similarity evidence.

---

## Software Used

* Emu
* Samtools
* SeqKit
* NCBI BLAST

---

## Input Data

The analysis used the alignment file generated during Exercise 1:

```text
results/emuout/sample01.fq_emu_alignments.sam
```

This SAM file contains read-level taxonomic assignments produced during Emu abundance estimation.



## Identification of Candidate Organisms

Taxonomic identifiers were extracted from the alignment file and ranked according to the number of assigned reads.

```bash
samtools view results/emuout/sample01.fq_emu_alignments.sam \
  | cut -f3 \
  | cut -d: -f1 \
  | sort \
  | uniq -c \
  | sort -nr
```

Among the identified taxa was:

```text
Salmonella enterica
Tax ID: 28901
Relative abundance: 4.4%
```

Because *Salmonella enterica* is an important foodborne pathogen and represented a moderate proportion of the sample, it was selected for further validation.



## Extraction of Salmonella Reads

Reads uniquely assigned to *Salmonella enterica* were extracted using mapping quality filtering and taxonomic identifier matching.

```bash
samtools view -e "mapq > 0" results/emuout/sample01.fq_emu_alignments.sam \
  | awk -F"\t" '$3 ~ "28901:emu_db.*"' \
  | cut -f1,10 \
  | seqkit tab2fx > results/read_extraction/salmonella_enterica.fa
```

A FASTQ version retaining sequencing quality information was also generated.

```bash
samtools view -e "mapq > 0" results/emuout/sample01.fq_emu_alignments.sam \
  | awk -F"\t" '$3 ~ "28901:emu_db.*"' \
  | cut -f1,10,11 \
  | seqkit tab2fx > results/read_extraction/salmonella_enterica.fq
```

## BLAST Validation

The extracted FASTA file was submitted to the NCBI Nucleotide BLAST service for independent taxonomic verification.

### Summary of Top BLAST Hits

The highest-scoring classified matches corresponded to multiple *Salmonella enterica* genomes and serovars, including:

* *Salmonella enterica* subsp. salamae
* *Salmonella enterica* serovar Enteritidis
* *Salmonella enterica* serovar Infantis
* *Salmonella enterica* serovar Newport
* *Salmonella enterica* serovar Dublin
* Additional complete *Salmonella enterica* chromosome sequences

### Alignment Statistics

| Metric           | Observed Range                           |
| ---------------- | ---------------------------------------- |
| Query Coverage   | ~90–95%                                  |
| Percent Identity | ~91.5–93.0%                              |
| E-value          | 0.0                                      |
| Match Type       | Complete genome and chromosome sequences |

Several environmental and uncultured bacterial 16S sequences also appeared among the top hits, which is expected because 16S rRNA genes are highly conserved among many bacterial taxa and public databases contain numerous environmental sequence submissions.

---

## Interpretation

The BLAST results strongly support the classification produced by Emu.

Key observations include:

* Multiple independent top-scoring matches corresponded to *Salmonella enterica* genomes.
* All major classified hits exhibited extremely significant alignments (E-value = 0.0).
* Query coverage exceeded 90% for the best matches.
* Percent identity approached 93%, which is consistent with identification using 16S rRNA sequence data.

Although the extracted reads were not sufficient to confidently resolve the exact serovar, the results clearly support assignment to the species *Salmonella enterica*.

The agreement between Emu classification and BLAST validation demonstrates that the taxonomic assignment was biologically plausible and supported by sequence similarity evidence.
